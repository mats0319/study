# 头像生成 Generate Avatar

根据输入内容生成像素风格图片，可用作默认头像

生成png图片，长宽比为1:1，整体上左右对称；图片主体为紧密排列的5*5方格（色块），外围有一圈白边

- 图片长宽像素数为`12a*12a`，其中`a`为用户输入的 **尺寸等级**
    - 每一个小方格边长为`2a`，外围的白边宽度为`a`
    - 举个例子，假设尺寸等级为4，则最终图片像素数为`48*48`
- 每个方格显示指定颜色或白色
    - 指定颜色：根据输入字符串计算，详见实现小节
- 为什么外围有一圈白边：可以方便剪裁为圆形而保留基本样式

## 实现 implement

1. 输入一个 **字符串**和想要的图片 **尺寸等级**，计算字符串hash
    - hash algorithm：`sha256`
    - 结果类型：`[]byte`（长度：32）
    - 相同字符串产生相同图案，不同尺寸仅意味着图片像素数不同
    - 默认尺寸等级：传入无效的尺寸等级时，使用默认尺寸等级（1级）
2. `32 = 15 + 4 + 13`：前15字节表示对应位置是否显示色块，接下来4个字节表示颜色，剩余13字节未使用
    - 是否显示色块：15个字节用来表示左侧两列与中间列的方格是否显示色块，图片左右对称
        - 对于每一个方格，如果相应字节的最后一个bit为1则显示色块、为0则显示白块
    - 色块的颜色：4个字节分别表示`r`、`g`、`b`、`a`
        - 如果透明度过低 (`opacity < 0.1`)，则将其设置为一个较低值 (`opacity: 0.25`)
3. 记录以上计算结果，使用`image`包编码图片信息，输出文件名和文件字节流
    - 文件名：`("%x_%d.png", hash[:6], size)`
        - 为什么不使用原文做文件名：原文可能包含`/`或其他不能用于文件名的特殊字符，同时其长度也不可控
