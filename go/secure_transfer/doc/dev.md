## 流式加密和加密层

因为同时兼容多种加密方式（整个加密、流式加密），所以首先抽象出一个加密层

流程概述：

1. 找到文件
2. 根据文件大小：
    - 10m及以下：一次性加载到内存
    - 10m以上：流式加密（一帧的大小为1m、并发加密）

详细设计：

1. 不同的加密方式对应不同的解密方式，需要将加密方式也写进文件，加密方式：
    - 写在文件开头，示例：`st 0 16 7 x [salt] [base nonce] [aad]`）
    - 写一个统一的开头：'st' 2 Byte
    - 一次性加密或流式加密：1 Byte
    - 用于密钥派生的salt：1 + 16 Byte （长度+明文，随机生成）
    - aes-gcm base nonce：1 + 7 Byte （长度+明文，随机生成）
        - aes-gcm nonce：12 Byte = 7 + 1 + 4，随机基础nonce、末帧标识、帧索引，  
          假设每一帧的大小为1m，4 Byte的帧索引可以安全加密4,294,967,296 MB（约 4 PB）大小的文件
    - 关联数据 (aad)：1 + x Byte （长度+明文，固定传一个吧）
2. 文件帧：（小文件没有这一概念）
    - 末帧标识：1 Byte
    - 帧索引：4 Byte
    - 有效长度：1 Byte
    - 有效内容：x Byte
3. 流式加密：读取、加密、写入，拆成不同的goroutine，同时为加密编写并发(?)
